# compare-students

Command that compares and analyzes grades between students

## Run
```bash
# Default run (top 3 vs bottom 3)
node student-comparison.js

# Specify particular students
node student-comparison.js STU001 STU005 STU010
```

## Features
- Basic info table (average, grade, highest/lowest score)
- Accuracy comparison by category
- Score trend analysis (rising/falling indicators)
- Average study time comparison
- Individual strength/weakness analysis
- Group statistics

## Output Format
- Comparison data in table format
- Visual bar charts
- Trend icons (↑/↓/→)
