# analyze-grades

Command that analyzes all student grades

## Run
```bash
node grade-analyzer.js
```

## Features
- Calculate the overall average score
- Visualize the grade distribution
- Compare average scores by class
- Average accuracy by category
- Extract the top/bottom 5 students
- Analyze recent score trends

## Prerequisites
- Requires the `student_data.json` file

## Example Output
```

========================
📈 Overall Statistics
  • Total students: 20 students
  • Overall average score: 67.9 pts

📊 Grade Distribution
```
