# create-report

Command that generates a comprehensive report in HTML format

## Run
```bash
node teacher-report.js
```

## Features
- Generate a visual dashboard
- Relative-grading distribution chart
- Lists of top-performing / needs-improvement students
- Performance graphs by category
- Overall analysis and improvement suggestions

## Grading Criteria (relative ranking)
- **Grade A**: Top 20% (1-20%)
- **Grade B**: Top 21-40%
- **Grade C**: Top 41-70%
- **Grade D**: Bottom 30% (71-100%)

## Output
- `teacher_report.html` file
- Viewable in a browser
- Print-optimized styles

## HTML Highlights
- Responsive design
- Gradient color theme
- Color coding by grade
- Mobile support
